# Project Arrakis

**Open-source engineering for Dune: Awakening self-hosting,
operations, observability, automation, security, and community tooling.**

Project Arrakis is an open-source engineering organization focused on
building production-oriented infrastructure and operational tooling for
the Dune: Awakening self-hosting ecosystem.

Our projects address the complete operational lifecycle of self-hosted
Dune environments: deployment, administration, monitoring, reliability,
security, automation, testing, release management, and community
integration.

---

## Project Ecosystem

### Dune: Awakening Docker
Core self-hosting platform and containerized server infrastructure.

### Dune Ops Observability
Operational telemetry, Prometheus integration, SOC/NOC visibility,
health models, and reliability monitoring.

### Dune Docker Addons
Governed extension and addon ecosystem.

### ACP Operations
Automation, Discord integration, upstream monitoring, CI validation,
and operational tooling.

### Deployment Engineering
Reference architectures, deployment automation, infrastructure
validation, and production-hardening guidance.

## Engineering Disciplines

| Discipline | Focus |
|---|---|
| Platform Engineering | Linux, Docker, deployment automation and lifecycle operations |
| SRE | Availability, health, readiness, telemetry and incident prevention |
| Observability | Prometheus, Grafana, operational metrics and alerting |
| Security | Least privilege, trust boundaries and secure software delivery |
| DevSecOps | CI/CD controls, SAST, secret scanning and release governance |
| Quality Engineering | Regression testing, failure-path testing and compatibility validation |
| Infrastructure | Networking, virtualization, storage and production deployment |
| Governance | Change controls, release evidence, risk management and operational ownership |

## Engineering Principles

- Secure defaults.
- Explicit trust boundaries.
- Least privilege.
- Reproducible deployment and recovery.
- Observable systems.
- Automated validation.
- Failure-path testing.
- Documented operational ownership.
- Safe upgrade and rollback paths.
